## Running the Projects

Each full-stack project contains a root `package.json` with helper commands.

Example:

```bash
cd 04-capstone-ecommerce
npm install
npm run install:all
npm run dev
```

For projects using MongoDB/JWT, copy the provided server `.env.example` file to `.env` and replace the example values.

## Deployment

The projects are prepared for:

- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas

Deployment requires your own cloud accounts and environment variables. No real credentials are included in this repository.
